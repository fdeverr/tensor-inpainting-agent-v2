# Assets

Put complete RGB benchmark images in this directory. Only use images that you
are allowed to redistribute when publishing the project.

`example.png` is the current Day 1 example image. Before publishing the project,
confirm that you have permission to redistribute it and document its source.

The Day 1 CLI creates a synthetic mask from a complete image so that the hidden
pixels remain available for final evaluation. A naturally damaged image cannot
produce a real PSNR or SSIM score unless its complete ground truth is known.
